This post exists mostly to prove the pipeline works. Here's what happens when I
add a new `.mdx` file to `content/blog/`:

1. The filename becomes the slug (`hello-world.mdx` → `/blog/hello-world`).
2. The frontmatter is validated against a [Zod](https://zod.dev) schema — a
   typo in `date` or a missing `description` fails the build.
3. Reading time, the sitemap entry, and the RSS item are all derived
   automatically.

## Code blocks

Syntax highlighting is handled by `rehype-pretty-code` (Shiki under the hood),
with light and dark themes:

```ts title="greet.ts" showLineNumbers
export function greet(name: string): string {
  // this line is highlighted
  return `Hello, ${name}!`;
}
```

Inline code like `const x = 42` works too.
