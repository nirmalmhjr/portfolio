## Project notes

- Code lives in `src/` (see the structure in frontend.mdc). Blog posts stay in `content/blog/` at the repo root.
- Every page gets its metadata from `createMetadata()` in `src/lib/seo.ts` (title, description, canonical, Open Graph, Twitter). Add new pages to `src/app/sitemap.ts`.
- After every edit, `.claude/settings.json` runs `pnpm dlx ultracite fix`, matching the Cursor hook in `.cursor/hooks.json`. Run `pnpm lint` and `pnpm typecheck` before committing.
- The phone number in `src/features/resume/utils/resume-document.ts` is for the PDF only. Never import that file from a `"use client"` component or move the number into `src/configs/site.ts`, because both end up in client JavaScript.
- `/resume.pdf` is generated by `src/app/resume.pdf/route.ts`. Don't add a static `public/resume.pdf`, because it would shadow the route. After any résumé content change, check that the PDF is still one page.
- Before any UI change, read `PRODUCT.md` (who the site is for) and `DESIGN.md` (colors, type scale, components, Do's and Don'ts) and follow them, even outside `/impeccable`. Text is never smaller than 11px. If a change adds a new token or pattern, update `DESIGN.md` too.
- `pnpm build` overwrites the `.next` folder that `pnpm dev` uses. For production checks, build a copy outside the repo instead.
